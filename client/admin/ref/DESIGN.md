## Brand & Style

The visual identity embodies the gravity of constitutional jurisprudence paired with the analytical precision of enterprise GraphRAG engineering. Designed for legal researchers, knowledge engineers, and high-court taxonomists, the interface operates as a high-density, mission-critical workspace. It projects absolute reliability, constitutional neutrality, and algorithmic transparency.

The aesthetic fuses **Corporate / Modern** discipline with **Dense Technical Utility**. It balances statutory authority—evoked through structured typographic hierarchy and deliberate structural rhythm—with cutting-edge AI observability: knowledge graph state visualizers, vector embedding index monitors, and Indian Code cross-referencing nodes. The visual tone remains calm, surgical, and sober, entirely eschewing theatrical consumer tech embellishments in favor of low-strain ergonomics during sustained operational shifts.

## Colors

The palette is engineered around an analytical Slate Blue gamut, ensuring extended reading comfort and high-density legal data scanning under ambient enterprise lighting.

- **Canvas & Backgrounds**: Base canvas defaults to `#E7EDF4`. The primary working container rests on `#EFF3F7`, while elevated floating panels, detail drawers, and context cards step up to `#F5F7FA`. Pure white (`#FFFFFF`) is reserved exclusively for primary input fields and focused document review sheets.
- **Brand & Interaction**:
  - `primary_color_hex` (`#2563A8`): Primary actions, active navigation anchors, and primary graph entity selections.
  - `secondary_color_hex` (`#183B5B`): Deep maritime navy for institutional authority; used in top-level app headers, section anchors, and graph cluster parent boundaries.
  - `tertiary_color_hex` (`#3B82D0`): High-clarity focal blue for vector pipeline updates, processing rings, and text highlights within citations.
  - `Soft Blue` (`#D9E7F5`): Used for semantic chips, entity relationship tags, hover states, and structural table headers.
- **Typography & Boundaries**:
  - Text Primary: `#17253A` (optimized for rigorous optical contrast against slate surfaces).
  - Text Secondary: `#526176` (supporting metadata, citation dates, corpus hashes).
  - Borders & Dividers: `#CDD9E5` across structural grids; `#B8CBDD` for focused active inputs.
- **Functional & Observability Accents**:
  - Verification & Precedent Established (Green): `#1E7E51` / Fill: `#E5F5EC`.
  - In Review / Ambiguous Precedent (Amber): `#B45309` / Fill: `#FEF3C7`.
  - Citation Overruled / Pipeline Block (Red): `#B91C1C` / Fill: `#FEE2E2`.

## Typography

The typographic hierarchy accommodates high-density legal language, canonical section codes, and real-time operational telemetry.

- **Primary Structure (`Space Grotesk`)**: Provides geometric precision and modern architectural authority for views, portal sections, and corpus-level metric panels.
- **Reading & Legal Narrative (`Manrope`)**: A clean, balanced sans-serif chosen for dense statutory text, judgment excerpts, ratio decidendi notes, and tabular data rows without visual fatigue.
- **System Telemetry & Citations (`JetBrains Mono`)**: Explicitly used for Indian Kanoon IDs, Act section tokens (e.g., `SEC-302-IPC`, `ART-21-COI`), embedding dimension status, latency metrics, and pipeline logs. Numerical tabular figures must always be aligned monospaced.

## Layout & Spacing

The portal uses a fluid 12-column engineering grid optimized for ultra-wide, desktop, and split-screen workbench environments.

- **Operational Layout System**:
  - Fixed left-hand navigation console: 256px wide, collapsible to 64px icon-only rail for expansive GraphRAG canvas views.
  - Multi-pane arrangement: Primary structural canvas utilizes fixed gutters of `1rem` (16px), expandable to `1.5rem` on 4K multi-monitor legal ops workstations.
  - Detail panels and statutory comparative diffs open into anchored right drawers (440px default width) layered over the grid.
- **Adaptive Breakpoints**:
  - `Desktop Large (>= 1440px)`: 12 columns, multi-stream layout (Knowledge Graph Canvas + Entity Schema Inspector + Execution Logs).
  - `Desktop Small (1024px - 1439px)`: 12 columns, tabbed secondary drawers, collapsed pipeline metrics.
  - `Tablet / Field Console (768px - 1023px)`: 8 columns, stacked card lists, graph canvas toggles to structured list view.
  - `Mobile (< 768px)`: 4 columns, critical monitoring only; operational actions locked behind confirmation sheets.

## Elevation & Depth

Visual hierarchy relies on **tonal layered surfaces** and **low-contrast architectural outlines**, deliberately avoiding heavy, diffuse consumer drop-shadows that clutter technical data density.

- **Layer 0 (Canvas Base)**: `#E7EDF4` — The global workstation backdrop.
- **Layer 1 (Card & Module Surfaces)**: `#EFF3F7` bounded by a crisp 1px border (`#CDD9E5`). Zero shadow.
- **Layer 2 (Elevated Workbenches & Active Nodes)**: `#F5F7FA` bordered by `#B8CBDD`, supported by a direct, surgical ambient shadow: `box-shadow: 0 2px 4px rgba(23, 37, 58, 0.04), 0 1px 2px rgba(23, 37, 58, 0.06)`.
- **Layer 3 (Overlays, Flyouts & Modals)**: `#FFFFFF` encased in a reinforced border (`#9AB4CB`) with an operational elevation shadow: `box-shadow: 0 8px 24px rgba(24, 59, 91, 0.12), 0 2px 6px rgba(24, 59, 91, 0.04)`.
- **Knowledge Graph Node Canvas**: Deep workspace nodes use a `#FFFFFF` fill with an inset indicator ring and an outer status aura mapped to entity degree weights (using `rgba(37, 99, 168, 0.15)`).

## Shapes

The design system employs a disciplined, professional corner radius (`roundedness: 1`), keeping components structured and compact.

- **Base Radius (0.25rem / 4px)**: Data inputs, table rows, code citations, and metric progress bars.
- **Container Radius (`rounded-lg` / 0.5rem / 8px)**: System cards, modal dialogs, GraphRAG entity inspect panels, and pipeline status boards.
- **Expanded Containers (`rounded-xl` / 0.75rem / 12px)**: Main graph canvas frame and major multi-pane boundary wrappers.
- **Pill Exceptions (`9999px`)**: System health pulse badges, verified precedent status tags, and graph relationship edge badges only.

## Components

### Buttons & Interactive Triggers
- **Primary Action**: Background `#2563A8`, text `#FFFFFF`, border `1px solid #1E528D`. Hover shifts to `#1D4F86`. Active state uses `#183B5B`. Font is `Manrope` 13px bold with 4px border radius.
- **Secondary / Technical**: Background `#EFF3F7`, text `#17253A`, border `1px solid #CDD9E5`. Hover activates to `#D9E7F5` with border `#9AB4CB`.
- **Destructive Action**: Background `#FEE2E2`, text `#B91C1C`, border `1px solid #FCA5A5`. Used for re-indexing pipeline teardowns or corpus purges.

### Form Inputs & Query Terminals
- **Input Fields**: Background `#FFFFFF`, border `1px solid #CDD9E5`, text `#17253A`, placeholder `#526176`. Focus state applies a rigid 1px outer ring `0 0 0 2px rgba(37, 99, 168, 0.2)` with a `#2563A8` border. Height is constrained to an efficient 34px for density.
- **Natural Language & Cypher Query Console**: Monospace text box styled in `#EFF3F7`, with inline syntax tokens for legal operators (`OVERRULED_BY`, `CITED_IN`, `READ_WITH`).

### Data Tables (Statutes & Judgments)
- Row height: 38px dense, 48px comfortable for multiline ratio decidendi summaries.
- Headers: Background `#D9E7F5`, text `#183B5B`, font `JetBrains Mono` 11px uppercase with `0.02em` tracking.
- Borders: Horizontal rule only (`1px solid #CDD9E5`), no vertical cell dividers. Alternate rows use a 50% opacity blend on `#EFF3F7`.

### Legal Citation & Graph Entity Chips
- Neutral Tag: Background `#D9E7F5`, text `#183B5B`, border `1px solid #B8CBDD`, font `JetBrains Mono` 11px.
- Constitutional Article Tag: `#EFF3F7` base with a `#2563A8` left border strip (3px width).

### Observability & Graph Cards
- Cards feature a structural top header bar separating operational controls from data bodies with a `#CDD9E5` 1px line.
- Node inspection cards display key-value metadata in a paired 2-column key list (`#526176` label, `#17253A` value in `JetBrains Mono`).

### Pipeline Progress Monitors
- Vector chunking & ingestion meters: 6px continuous segment tracks. Unfilled track uses `#D9E7F5`; active processing uses `#3B82D0`; completed segments use `#1E7E51`. Accompanied by real-time token/sec numerical indicators in `label-sm`.
